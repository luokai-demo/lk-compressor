# 第三方组件与许可

自有 Python/PowerShell 代码使用 MIT。`image/icon.jpg` 为项目既有图标，本仓库不另行授予该图片的再分发授权；如需复用或重新发布，请先确认图片权利。

Windows EXE 内嵌的组件分别遵循上游许可证，不能把整个打包产物简单视为仅受 MIT 约束。构建工具包和 EXE 的 `licenses/` 目录保留现有发行包中的许可证、版权和上游说明。

| --- | --- | --- |

上表提供对应上游源码；工具包保留现有发行包中的许可及构建说明，以便追溯。FFmpeg 启用的组件与许可取决于其具体构建配置，可运行 `ffmpeg.exe -buildconf` 查看。涉及 GPL/LGPL 的再分发义务按相应上游许可证履行；再分发修改后的工具时还须提供对应源码和修改说明。

本仓库没有对这些第三方原生工具做源码修改。更新它们时，请一并更新许可、版本记录、校验值并重新执行 Windows 构建验证。
